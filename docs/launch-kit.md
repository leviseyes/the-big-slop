## Short announcement

I’m open-sourcing The Big Slop: a self-hosted filmmaking studio that takes a script through reference images, storyboards, AI video clips and final assembly. You review the cast, shots and cost before moving on. Bring your own OpenAI and Higgsfield API keys; generation is paid separately.

The goal is a slopless feature film from just a script. Today it’s an experimental concept-film tool, with imperfect continuity and plenty to improve. I’d love clean-install feedback and contributors working on continuity, cost visibility and self-hosting.

https://github.com/leviseyes/the-big-slop

If it’s useful, a star helps people discover it.

## Demo capture outline (60–90 seconds)

- 0–10s: explain the goal and the alpha limitations.
- 10–25s: import the original sample script and choose runtime/languages.
- 25–40s: show reference editing and storyboard approval.
- 40–55s: show the estimate/commit boundary and saved progress.
- 55–75s: show a finished original sample only if actually generated and reviewed; otherwise clearly state that this is a UI walkthrough.
- End: repository URL, own-key requirement, contribution invitation.

## Launch channels

Publish the GitHub release first. Then share a contextual post in relevant filmmaking/self-hosting communities, respecting each community's rules. Submit to Show HN or similar venues only with an honest demo and clear paid-provider disclosure. Do not buy stars, automate spam or promise model quality the app cannot deliver.
