# Try the studio

This is a walkthrough of the real self-hosted UI. No generated movie is bundled or represented as a quality benchmark.

1. Install and sign in. Click **Try a sample script** for *The Last Customer*.
2. Explore the format, runtime, languages and look controls. Saving a script does not call a provider.
3. With your API accounts connected, start planning. This begins paid LLM usage. Review the plan before approving images.
4. Inspect the reference library; change several descriptions or upload replacements, then press Done.
5. Review the sequential storyboard. Accept individual panels or all current shots, then explicitly continue.
6. Review the video estimate and commit only when ready for charges. Watch progress through generation and assembly.
7. Watch the finished concept film. Look for pacing opportunities as well as AI mistakes.

For a zero-provider-cost verification, run `npm run test:workers`: it executes the real worker against intercepted provider fixtures and assembles synthetic clips with FFmpeg. It tests mechanics, not cinematic quality.
