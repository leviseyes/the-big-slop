# Changelog

## 0.1.0 — initial open-source alpha

- Independent single-owner authentication, salted password hashing, signed cookies and login rate limiting.
- Local D1/R2 setup, persistent render worker, Docker configuration and Cloudflare deployment guide.
- Script/idea workflow, references and batch edits, storyboard review, cost acceptance, Seedance clips and FFmpeg assembly.
- Production categories, series reference reuse, asset downloads and private viewing library.
- Durable request checkpoints, continuity-aware references and bounded safe recovery.
- Apache 2.0 licensing, original example screenplay, installation/key guides, community files and automated checks.
- Fresh sanitized source history; no private productions, credentials or hosted deployment identifiers.

Early alpha limitations and verification scope are documented in `docs/limitations.md` and the release notes. AI provider usage is paid separately.
